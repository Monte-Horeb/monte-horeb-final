# Images

`logo.jpg` is a generated stand-in using the site's navy/gold palette.
Every other file here is a visibly hatched placeholder.

Replace them with real photographs, keeping the same filenames — the code
references these paths directly (see `src/content/church-info.ts` and
`src/content/leadership.ts`). Recommended sizes:

- `logo.jpg` — square, 512×512 or larger
- `hero.jpg` — 1600×900
- `about.jpg` — 1200×800
- `leadership/*.jpg` — square, 600×600
